## Upgrading to the Latest Version

Follow these steps to ensure your AC instance runs the latest version.

<Steps>
  <Step title="Check Current Version" icon="package">
    Run the version check command in your project root.
    
    <CodeGroup tabs="npm,yarn">
    ````bash
    npm run version
    ````
    ````bash
    yarn version
    ````
    </CodeGroup>
  </Step>
  
  <Step title="Update Dependencies" icon="upload">
    Pull the latest changes and reinstall.
    
    <CodeGroup tabs="npm,yarn">
    ````bash
    npm update ac-docs
    ````
    ````bash
    yarn upgrade ac-docs
    ````
    </CodeGroup>
  </Step>
  
  <Step title="Restart Services" icon="refresh-cw">
    Restart your AC server.
    
    ````bash
    npm run dev
    ````
  </Step>
</Steps>
